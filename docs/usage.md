# Usage

```python
import finance_quant_generator
```

Each module is self-contained; see docstrings for the API:

- `finance_quant_generator.data_generator` — The main entry point for the synthetic data generator.
- `finance_quant_generator.utils` — Utility functions used throughout the project.
- `finance_quant_generator.market_models` — Statistical models for generating market time series data.
- `finance_quant_generator.risk_metrics` — Functions to calculate statistically-plausible risk metrics.
- `finance_quant_generator.config` — Configuration and parameter management for the generator.
- `finance_quant_generator.tests_test_data_generator` — Tests for the synthetic data generator.
